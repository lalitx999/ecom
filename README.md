# Lumé - ร้านค้าออนไลน์ (Django + PostgreSQL + Ajax + Bootstrap 5.3.8)

```bash
source .venv/bin/activate
python manage.py migrate
python manage.py seed_shop          # สินค้าตัวอย่าง 24 รายการ
python manage.py createsuperuser    # สำหรับเข้า /admin/ จัดการสินค้า
python manage.py runserver
```

- ฐานข้อมูล: PostgreSQL `ecommerce_db` (ตั้งค่าผ่านตัวแปร `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`)
- Bootstrap ใช้ไฟล์ใน `bootstrap-5.3.8-dist/` (ไม่ใช้ CDN)
- ไอคอน: `static/img/icons.svg` (SVG เส้นเดียวสี ไม่มีอิโมจิ)
- ตะกร้า: เก็บใน session, API แบบ Ajax ที่ `/cart/add/`, `/cart/update/`, `/cart/remove/`

## ขั้นตอนสั่งซื้อ
- สมัคร/เข้าสู่ระบบด้วยอีเมล (`/register/`, `/login/`) ตะกร้าไม่หายเมื่อล็อกอิน
- `/checkout/` กรอกที่อยู่ เลือก เก็บเงินปลายทาง หรือ โอนเงิน/พร้อมเพย์ (ยังไม่เชื่อมระบบชำระเงินอัตโนมัติ)
- ตัดสต็อกด้วย `SELECT ... FOR UPDATE` ภายใน transaction เดียว ป้องกันสั่งซื้อสินค้าชิ้นสุดท้ายซ้ำ
- ค่าส่ง 50 บาท ฟรีเมื่อซื้อครบ 500 บาท (`SHIPPING_FEE`, `FREE_SHIPPING_THRESHOLD` ใน settings)
- ใส่ข้อมูลบัญชีรับโอนจริงที่ `PAYMENT_TRANSFER_INFO` ใน settings
- แอดมินเปลี่ยนสถานะคำสั่งซื้อที่ `/admin/` การเลือก "ยกเลิก" จะคืนสต็อกให้อัตโนมัติ
- รันเทสต์: `python manage.py test shop`

## แผงจัดการร้าน (`/manage/`)
ระบบหลังบ้านเขียนใหม่ทั้งหมด (ไม่ใช้ Django Admin) เข้าได้เฉพาะบัญชี `is_staff`
- **แดชบอร์ด:** ยอดขายวันนี้/30 วัน, กราฟรายวัน, ออเดอร์รอจัดส่ง/รอชำระเงิน, สินค้าใกล้หมด, สินค้าขายดี
- **สินค้า / หมวดหมู่:** เพิ่ม แก้ไข ลบ อัปโหลดรูป แก้สต็อกและเปิด-ปิดการแสดงสินค้าในตารางแบบ Ajax
- **คำสั่งซื้อ:** ค้นหา/กรอง เปลี่ยนสถานะ (ยกเลิก = คืนสต็อก) พิมพ์ใบจัดส่ง ส่งออก CSV
- **ผู้ใช้ (เฉพาะผู้ดูแลสูงสุด):** เพิ่ม แก้ไขบทบาท ปิดใช้งาน ตั้งรหัสผ่านใหม่ ลบ (ลบไม่ได้ถ้ามีออเดอร์)
- **รายงาน:** เลือกช่วงวันที่ รายวัน/รายเดือน สินค้าขายดี ตามหมวดหมู่/วิธีชำระเงิน/สถานะ ส่งออก CSV (เปิดใน Excel ได้) และพิมพ์
- ยอดขาย = คำสั่งซื้อที่ไม่ถูกยกเลิก (รวมค่าส่ง) นับตามวันที่สั่งซื้อ เวลาไทย
- สร้างผู้ดูแลคนแรก: `python manage.py createsuperuser` (ล็อกอินได้ทั้งอีเมลและ username)
- ข้อมูลตัวอย่างสำหรับดูกราฟ: `python manage.py seed_demo_orders` ลบด้วย `python manage.py seed_demo_orders --purge`

## แจ้งเตือนและการจัดส่ง
- ลูกค้าสั่งซื้อ → อีเมลยืนยันถึงลูกค้า + อีเมลแจ้งผู้ขาย (ทุกบัญชี staff ที่เปิดใช้งาน และ `SHOP_NOTIFY_EMAILS`)
- โอนเงิน: ลูกค้าแนบสลิปที่หน้าคำสั่งซื้อ → แจ้งผู้ขาย → กด "ยืนยันรับชำระเงิน" → อีเมลถึงลูกค้า (สลิปเก็บใน `private_media/` ดูได้เฉพาะเจ้าของออเดอร์และ staff)
- จัดส่ง: เลือกขนส่ง + เลขพัสดุ → ระบบอีเมลเลขพัสดุและลิงก์ติดตามให้ลูกค้าอัตโนมัติ (แก้เลขพัสดุภายหลังจะส่งซ้ำ มีปุ่มส่งอีเมลอีกครั้ง)
- ยกเลิกออเดอร์ → คืนสต็อกและอีเมลแจ้งลูกค้า
- ตอนพัฒนา อีเมลจะแสดงในหน้าต่างที่รัน `runserver` (ยังไม่ส่งจริง) ตั้ง `EMAIL_HOST` เพื่อส่งจริง ดู `.env.example`
- ลืมรหัสผ่าน: `/password-reset/`
- ลิงก์ติดตามพัสดุตั้งที่ `CARRIER_TRACKING_URLS` ใน settings (มี ไปรษณีย์ไทย, Kerry, Flash, DHL) ควรทดสอบลิงก์ก่อนใช้จริง ขนส่งที่ไม่มีลิงก์จะส่งเฉพาะเลขพัสดุ
- Deploy: ดู `DEPLOY.md`

## Footer
- Footer มีลิงก์ช้อปปิ้ง หมวดหมู่ บัญชี/ตะกร้า ค่าจัดส่ง วิธีชำระเงิน และลิขสิทธิ์ ลิงก์พวกนี้มาจากข้อมูลจริงของร้านอัตโนมัติ
- ข้อมูลติดต่อ (เบอร์โทร อีเมล LINE เวลาทำการ ที่อยู่ Facebook/Instagram/TikTok และคำโปรย) ตั้งผ่านตัวแปร `SHOP_*` ตาม `.env.example` ค่าที่ว่างจะไม่แสดง
- หน้านโยบาย (คืนสินค้า ความเป็นส่วนตัว เงื่อนไข) ยังไม่มี จึงยังไม่ใส่ลิงก์ใน Footer
