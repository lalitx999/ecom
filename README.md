# NS SELECT - ร้านค้าออนไลน์ (Django + PostgreSQL + Ajax + Bootstrap 5.3.8)

```bash
source .venv/bin/activate
python manage.py migrate
python manage.py import_ns_select   # นำเข้าสินค้าจริง 20 รายการจาก data/ns_select_products.json + รูปใน Work/
python manage.py createsuperuser    # สำหรับเข้าแผงจัดการร้าน /manage/
python manage.py runserver
```

- ฐานข้อมูล: PostgreSQL `ecommerce_db` (ตั้งค่าผ่านตัวแปร `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`)
- Bootstrap ใช้ไฟล์ใน `bootstrap-5.3.8-dist/` (ไม่ใช้ CDN)
- ไอคอน: `static/img/icons.svg` (SVG เส้นเดียวสี ไม่มีอิโมจิ)
- ตะกร้า: เก็บใน session (อ้างอิงตัวเลือกสินค้า `variant_id`), API แบบ Ajax ที่ `/cart/add/`, `/cart/update/`, `/cart/remove/`

## โครงสร้างสินค้า
- **Product** หน้าสินค้า (หมวดหมู่, แบรนด์, รายละเอียด, สิ่งที่อยู่ในชุด, วิธีใช้, วันหมดอายุ, ประเทศที่ผลิต)
- **ProductVariant** ตัวเลือกที่ซื้อได้ = สี × ไซซ์ มีราคา ราคาปกติ (ขีดฆ่า) สต็อก SKU และ "พร้อมส่ง" ของตัวเอง สินค้าที่ไม่มีตัวเลือก (เช่น ชุดครีม) มี 1 ตัวเลือกที่เว้นสี/ไซซ์ว่าง
- **ProductImage** หลายรูปต่อสินค้า ผูกกับสีได้ (เลือกสีแล้วรูปเปลี่ยน)
- **Brand** แบรนด์ (ใช้กรองสินค้า)
- ข้อมูลทั้งหมดในหน้าร้านมาจากฐานข้อมูล: แบนเนอร์หน้าแรก = สินค้าที่ติ๊ก "แสดงในแบนเนอร์หน้าแรก", ปุ่มลัด = หมวดหมู่
- `import_ns_select` รันซ้ำได้: อัปเดตราคา/ข้อมูล แต่ไม่ทับสต็อกที่แก้ไว้ และไม่เพิ่มรูปซ้ำ (สต็อกเริ่มต้น 1 ชิ้นต่อตัวเลือกที่มีราคา สีที่ไม่มีราคาในภาพได้ราคาเดียวกับสีที่รู้ราคาและสต็อก 0)

## ขั้นตอนสั่งซื้อ
- สมัคร/เข้าสู่ระบบด้วยอีเมล (`/register/`, `/login/`) ตะกร้าไม่หายเมื่อล็อกอิน
- `/checkout/` กรอกที่อยู่ เลือก เก็บเงินปลายทาง หรือ โอนเงิน/พร้อมเพย์ (ยังไม่เชื่อมระบบชำระเงินอัตโนมัติ)
- ตัดสต็อกด้วย `SELECT ... FOR UPDATE` ภายใน transaction เดียว ป้องกันสั่งซื้อสินค้าชิ้นสุดท้ายซ้ำ
- ค่าส่ง / ยอดส่งฟรี, บัญชีรับโอน, พร้อมเพย์, ข้อมูลติดต่อ และโลโก้ ตั้งที่ `/manage/settings/` (เฉพาะผู้ดูแลสูงสุด)
- แอดมินเปลี่ยนสถานะคำสั่งซื้อที่ `/manage/` การเลือก "ยกเลิก" จะคืนสต็อกให้ตัวเลือกนั้นอัตโนมัติ
- รันเทสต์: `python manage.py test shop dashboard`

## แผงจัดการร้าน (`/manage/`)
ระบบหลังบ้านเขียนใหม่ทั้งหมด (ไม่ใช้ Django Admin) เข้าได้เฉพาะบัญชี `is_staff`
- **แดชบอร์ด:** ยอดขายวันนี้/30 วัน, กราฟรายวัน, ออเดอร์รอจัดส่ง/รอชำระเงิน, ตัวเลือกสินค้าใกล้หมด, สินค้าขายดี
- **สินค้า / หมวดหมู่:** เพิ่ม แก้ไข ลบ ตารางตัวเลือก (สี × ไซซ์ ราคา สต็อก) และรูปหลายรูปในหน้าเดียว เปิด-ปิดการแสดงสินค้าแบบ Ajax แก้สต็อกตัวเลือกที่ใกล้หมดได้จากแดชบอร์ด
- **คำสั่งซื้อ:** ค้นหา/กรอง เปลี่ยนสถานะ (ยกเลิก = คืนสต็อก) พิมพ์ใบจัดส่ง ส่งออก CSV
- **ผู้ใช้ (เฉพาะผู้ดูแลสูงสุด):** เพิ่ม แก้ไขบทบาท ปิดใช้งาน ตั้งรหัสผ่านใหม่ ลบ (ลบไม่ได้ถ้ามีออเดอร์)
- **หน้าเนื้อหา/นโยบาย (`/manage/pages/`):** มีฉบับร่าง นโยบายคืนสินค้า / ความเป็นส่วนตัว / เงื่อนไข ให้กรอกช่อง [ ] แล้วกดเผยแพร่ ลิงก์จะขึ้นใน footer และหน้า terms กับ privacy-policy ที่เผยแพร่แล้ว ลูกค้าต้องติ๊กยอมรับตอนสมัคร
- **ความปลอดภัย:** ใส่รหัสผ่านผิด 5 ครั้งต่อบัญชี (หรือ 20 ครั้งต่อ IP) ใน 15 นาที จะถูกล็อกชั่วคราว ขอรีเซ็ตรหัสผ่านถูกจำกัดต่อ IP และต่ออีเมล
- **รายงาน:** เลือกช่วงวันที่ รายวัน/รายเดือน สินค้าขายดี ตามหมวดหมู่/วิธีชำระเงิน/สถานะ ส่งออก CSV (เปิดใน Excel ได้) และพิมพ์
- ยอดขาย = คำสั่งซื้อที่ไม่ถูกยกเลิก (รวมค่าส่ง) นับตามวันที่สั่งซื้อ เวลาไทย
- สร้างผู้ดูแลคนแรก: `python manage.py createsuperuser` (ล็อกอินได้ทั้งอีเมลและ username)

## แจ้งเตือนและการจัดส่ง
- ลูกค้าสั่งซื้อ → อีเมลยืนยันถึงลูกค้า + อีเมลแจ้งผู้ขาย (ทุกบัญชี staff ที่เปิดใช้งาน และ `SHOP_NOTIFY_EMAILS`)
- โอนเงิน: ลูกค้าแนบสลิปที่หน้าคำสั่งซื้อ → แจ้งผู้ขาย → กด "ยืนยันรับชำระเงิน" → อีเมลถึงลูกค้า (สลิปเก็บใน `private_media/` ดูได้เฉพาะเจ้าของออเดอร์และ staff)
- จัดส่ง: เลือกขนส่ง + เลขพัสดุ → ระบบอีเมลเลขพัสดุและลิงก์ติดตามให้ลูกค้าอัตโนมัติ (แก้เลขพัสดุภายหลังจะส่งซ้ำ มีปุ่มส่งอีเมลอีกครั้ง)
- ยกเลิกออเดอร์ → คืนสต็อกและอีเมลแจ้งลูกค้า
- ตอนพัฒนา อีเมลจะแสดงในหน้าต่างที่รัน `runserver` (ยังไม่ส่งจริง) ตั้ง `EMAIL_HOST` เพื่อส่งจริง ดู `.env.example`
- ลืมรหัสผ่าน: `/password-reset/`
- ลิงก์ติดตามพัสดุตั้งที่ `CARRIER_TRACKING_URLS` ใน settings (มี ไปรษณีย์ไทย, Kerry, Flash, DHL) ควรทดสอบลิงก์ก่อนใช้จริง ขนส่งที่ไม่มีลิงก์จะส่งเฉพาะเลขพัสดุ
- Deploy: ดู `DEPLOY.md`
